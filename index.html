支持格式见下方说明。

☁ 同步到服务器（永久保存你的题目与图片）

当前为纯静态托管，浏览器里的题目 / 图片默认只存在本机，换网址或清缓存会丢失。点「导出」生成含图片的备份文件，把它发给我，我会合并进服务器题库并重新部署；之后任意网址、任意设备打开都会自动加载你的题目和图片，不再丢失。

🖼 手机上部分图片不显示？

手机（尤其 iOS Safari）无法渲染过大的图片。点下面按钮，会把你已保存的大图压缩到手机可正常显示的尺寸（仅处理超过 300KB 的图，不丢题）。压缩后在手机上刷新页面即可显示。

支持的格式

[
  {
    "question": "题干内容？",
    "options": ["选项A", "选项B", "选项C", "选项D"],
    "answer": 0,
    "explanation": "解析（可选）",
    "category": "分类名",
    "difficulty": "简单",
    "imageData": "题目图片 base64（可选）",
    "audioData": "听力音频 base64（可选）"
  }
]
question,options,answer,explanation,category,difficulty
题干内容？,选项A|选项B|选项C|选项D,0,解析文字,分类名,简单
  • CSV 的 options 用 | 分隔各选项；answer 可为序号 0–3 或字母 A–D。
  • 缺少 category / difficulty 时自动补默认值；缺少 explanation 不阻断导入。
  • 导入采用合并策略：与现有题库按题干去重，不会丢失已有题目。
  • JSON 题目可带 imageData / audioData（base64）字段，分别作为题目图片与听力音频。
